# 贡献指南 (Alpha)

感谢你对 rust-igraph 的关注！本项目目前处于 alpha 阶段，主要由单人 + AI 协作开发。

## 如何参与

1. **报告问题**：在 [GitHub Issues](https://github.com/Totoro-jam/rust-igraph/issues) 提交 bug 报告或功能请求
2. **提交 PR**：fork 仓库，创建分支，提交 PR
3. **完善文档**：修正文档中的错误或添加示例

## 代码规范

- 提交信息格式：`<type>(<scope>): <short why>`
- 类型：`feat / fix / test / docs / refactor / perf / chore`
- 一个 AWU = 一个 PR

详细规范请参阅 [CLAUDE.md](https://github.com/Totoro-jam/rust-igraph/blob/main/CLAUDE.md)
